# T-REX LEARN ULTRA 🦖

منصة تعليمية رقمية فائقة السرعة مخصصة لطلاب نظم معلومات الأعمال، تعرض المقررات والمواد الدراسية وتوفر التحميل المباشر للملفات والمراجع.

## 🛠️ المعمارية والتقنيات (Tech Stack)

* **الطار الرئيسي:** Next.js 14 (App Router)
* **التوليد الثابت:** Static Site Generation (SSG) بالكامل لضمان أقصى سرعة تحميل.
* **التنسيق:** Tailwind CSS (Amber Theme)
* **قاعدة البيانات:** ملف محلي خفيف (`lib/data.json`) مع دوال معالجة في (`lib/courses.ts`) بدون أي قاعدة بيانات خارجية.
* **الاستضافة:** Vercel
